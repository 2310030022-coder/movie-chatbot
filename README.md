
# 🎬 MovieMate — Mood-Based Movie Recommendation Chatbot

## Project Overview
MovieMate is an interactive movie recommendation system that suggests films based on users' moods, interests, favorite genres, language preferences, and desired movie duration.

## Key Features
- Mood-based movie recommendations
- Interactive movie chatbot
- Natural-language keyword matching
- Genre, language, and duration filters
- Curated multilingual movie database
- Movie descriptions and release information
- IMDb movie search links
- Where-to-watch search links
- Personalized movie discovery
- Dark-themed interactive interface

## Technologies Used
Python, Streamlit, Rule-Based NLP, Recommendation Systems, GitHub

## How It Works
The chatbot identifies mood and preference keywords from user input and ranks movies using a rule-based recommendation algorithm.

## Limitations
Recommendations come from a curated catalog rather than a live movie database. The project does not use a generative language model.
